# Cyber Attack Radar

A free, public, live dashboard of cyber attacks worldwide: breaking incident reports from 12 security newsrooms, a global attack map, crypto hacks (DefiLlama), and actively exploited vulnerabilities (CISA KEV).

Everything is a single static `index.html`. Each visitor's browser fetches the latest data directly; no server, account or API key needed.

Hosted with GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
